# 🎨 Splash Vendetta

**Splash Vendetta** es un Shooter Táctico 3D donde la estrategia, el sigilo y la pintura se combinan en una experiencia única. 

## 📖 Sinopsis
El jugador toma el control de **Skoll**, un personaje en busca de venganza. Armado con marcadoras de pintura de alta tecnología, Skoll debe infiltrarse y dominar los escenarios utilizando tácticas de combate no convencionales.

## ⚙️ Mecánica Nuclear
El pilar de la jugabilidad consiste en el disparo de **proyectiles dinámicos de pintura** que alteran el entorno visual y sonoro en tiempo real al impactar. 

La pintura neón genera un fuerte contraste visual contra las atmósferas lúgubres del juego, como el nivel tutorial: **"El Refugio"**.

## 🚀 Características Principales
* **Género:** Acción / Shooter Táctico 3D.
* **Estilo Visual:** Contraste de entornos oscuros con colores neón vibrantes.
* **Interactividad:** Modificación del entorno en tiempo real mediante físicas y colisiones de pintura (Desarrollado en Unity).
